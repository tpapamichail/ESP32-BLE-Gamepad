Βοήθεια

Από αυτή τη σελίδα μπορείτε να αλλάξετε το όνομα χρήστη και τον κωδικό πρόσβασης που χρησιμοποιούνται για την πρόσβαση στο web interface του ESP32 BLE Gamepad.

  • Όνομα Χρήστη: Πρέπει να έχει τουλάχιστον 3 χαρακτήρες.
  • Κωδικός Πρόσβασης: Πρέπει να έχει τουλάχιστον 3 χαρακτήρες.
  • Επιβεβαίωση Κωδικού: Πρέπει να ταιριάζει με τον νέο κωδικό πρόσβασης.

Σημείωση: Μετά την αλλαγή των διαπιστευτηρίων, θα χρειαστεί να συνδεθείτε ξανά με τα νέα στοιχεία σύνδεσης. Παρακαλούμε θυμηθείτε τα νέα σας διαπιστευτήρια, καθώς δεν υπάρχει διαδικασία ανάκτησης κωδικού.

Προεπιλεγμένα διαπιστευτήρια: Αν ξεχάσετε τα διαπιστευτήριά σας, μπορείτε να επαναφέρετε τις προεπιλεγμένες ρυθμίσεις από τη σελίδα Ρυθμίσεις. Τα προεπιλεγμένα διαπιστευτήρια είναι: admin / admin
